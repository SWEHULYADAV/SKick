# Specialist Integration Registry

SKick is the coordinator. Specialist skills/plugins/harnesses may own a narrower phase when installed and materially useful; none are mandatory dependencies.

## First-class optional integrations
- **Superpowers** — engineering method: design/planning, TDD, debugging, subagents, review and completion verification. See `superpowers.md`.
- **Serena** — semantic code intelligence; handled by `core/serena-integration.md` and `core/mcp-stack.md`.
- **Hugging Face** — AI/ML Hub, datasets/models/training/evals/papers/Jobs. See `huggingface.md`.
- **Security/review specialists** — Codex Security, CodeRabbit, Trail of Bits and Sentry skill workflows. See `security-specialists.md`.
- **Harness/eval backends** — OpenAI Symphony/Harness Engineering patterns, mini-SWE-agent, Open SWE/Deep Agents, Pydantic AI Harness, Inspect AI, Harbor/Terminal-Bench. See `harnesses-and-evals.md`.
- **Frontend/browser** — Vercel stack skills and agent-browser routing. See `frontend-browser-specialists.md`.
- **Cloud/data** — AWS Agent Toolkit, Azure MCP/skills and MCP Toolbox for Databases. See `cloud-and-data-platforms.md`.
- **Research providers** — optional Exa/Tavily/Firecrawl one-of routing. See `research-providers.md`.
- **Agent control references** — Piebald/Claude Code prompt corpus, Gemini/Qwen memory, Karpathy autoresearch, Kimi lifecycle hooks, Cline worktrees/checkpoints and Smart MCP Proxy patterns. See `agent-control-patterns.md`.

## Rules
1. Detect availability; never claim an integration is installed without evidence.
2. Do not auto-install a specialist merely because it exists.
3. Give one workflow owner to each phase and pass compact task/evidence state.
4. Prefer a native capability if it already does the job with less risk/context.
5. Keep SKick's user objective, evidence/version rules, untrusted-content boundary, action approvals and provenance requirements.
6. Qualify downloaded skills/MCPs before activation and resolve mutable upstream instructions.
7. If a specialist is absent/fails, use SKick-native fallback and disclose only material capability loss.
