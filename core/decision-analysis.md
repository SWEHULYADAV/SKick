# Decision Analysis Under Uncertainty

## Purpose
Turn research into a defensible choice when multiple options, uncertain evidence, asymmetric downside, or switching costs matter.

## Decision frame
Define:
`decision -> options -> hard constraints -> criteria -> evidence -> uncertainties -> downside/irreversibility -> switching cost -> time horizon -> what would change the choice`.

Do not hide an unresolved factual question inside a subjective score.

## Separate facts from preferences
- **facts/evidence**: measurable compatibility, price, performance, legal status, failure rate, maintenance, clinical effect, etc.;
- **assumptions**: forecasts, adoption, future scale, behavior under uncertainty;
- **preferences/weights**: speed vs cost, simplicity vs flexibility, risk tolerance, reversibility.

## Dominance and elimination
First remove options that violate hard constraints or are clearly dominated. Do not build elaborate weighted matrices to compare an option that cannot satisfy the requirement.

## Reversibility and option value
When uncertainty is high, prefer a reversible experiment/prototype/migration step that buys information before an irreversible commitment.

## Sensitivity
For a recommendation, identify the few uncertain inputs/weights that could flip the decision. Test plausible ranges rather than presenting one arbitrary score as objective truth.

## Expected value
Use expected-value/probability calculations only when probabilities and outcomes are meaningful enough to justify them. Label subjective probabilities and scenario assumptions.

## Robust recommendation
A decision is stronger when it remains preferred across reasonable uncertainty ranges and failure scenarios. If the winner changes easily, report the decision as fragile and specify the next information-gathering experiment.

## Post-decision verification
Define leading indicators/guardrails and a review point so a decision can be revisited if assumptions fail.
